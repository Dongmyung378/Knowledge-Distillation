# 시스템 구조

실행 단계에서는 표지판 영역을 잘라낸 이미지를 입력받아 표지판 종류를 예측합니다. 학습 단계에서는 큰 교사의 클래스별 확률로 작은 학생을 지도합니다. 독립 학습 기준 모델은 같은 작은 구조를 사용하되 교사의 도움을 받지 않습니다. 시드로 의사 난수 시작 조건을 정해 두 학생 학습 경로의 조건을 맞춥니다. 이후 저장한 학생을 CPU 추론 파일로 변환하며, 변환 성공과 정확도 평가 및 처리 시간 측정은 각각 별도로 확인합니다.

GTSRB의 43개 클래스를 대상으로 MobileNetV2 교사 모델, 독립적으로 학습한 소형 학생 모델, 지식증류 학생 모델을 비교합니다. 기준 학생과 증류 학생은 동일한 34,406개 파라미터 구조를 사용합니다. 추론 그래프는 같고, 지식증류는 배포 모델 대신 학습 목적함수를 변경합니다.

## 입력과 모델 경계

모든 모델은 `[0,1]`로 정규화한 96 x 96 RGB 이미지를 받고 43개 클래스의 로짓을 출력합니다. 교사 모델은 ImageNet 사전 학습 MobileNetV2 앞에 `Rescaling(2.0, offset=-1.0)`을 포함하여 백본에 필요한 `[-1,1]` 범위를 전달합니다. 따라서 데이터 로더나 공개 추론 CLI에 교사 전용 정규화를 별도로 적용할 필요가 없습니다.

소형 학생은 깊이별 분리 합성곱 블록 3개, 전역 평균 풀링, 작은 완전 연결 분류기를 사용합니다. 모델 파일은 표준 Keras 계층으로 구성하며 별도의 증류 래퍼 없이 로딩할 수 있습니다. 추론 시 softmax를 한 번 적용하여 클래스 확률을 산출합니다. TFLite 추론은 텐서의 양자화 정보를 읽어 입력 양자화와 출력 역양자화를 적용합니다.

## 학습 목적함수

```text
hard_loss = cross_entropy(labels, student_logits)
soft_loss = KL(softmax(teacher_logits / T), softmax(student_logits / T))
loss = alpha * hard_loss + (1 - alpha) * T**2 * soft_loss
```

교사는 `training=False`로 호출하며 학생 학습 중 교사 가중치를 변경하지 않습니다. 기준 모델과 증류 모델의 클래스 가중치, 증강, 학습 예산 및 초기화 정책을 일치시킵니다. 검증에서는 0으로 고정된 로그 대신 실제 분류 손실과 정확도를 기록합니다. 검증 집합에서 선택한 최적 체크포인트를 저장하고 최종 평가 전에 다시 불러옵니다.

## 데이터 경계

공식 학습 자료를 클래스별로 층화하면서 표지판 트랙 단위로 학습, 검증, 동결 평가 집합으로 나눕니다. 같은 트랙의 이미지가 집합 경계를 넘지 않도록 합니다. 상대 경로, 라벨, 트랙 ID, 파일 크기와 SHA-256을 명세에 기록하고, 로딩할 때 실제 파일과 대조합니다.

학습 및 모델 선택에는 학습과 검증 집합만 사용합니다. 최종 동결 평가 집합은 모델, 데이터, 소스와 설정의 해시를 고정한 뒤 평가합니다. 공식 테스트 자료는 최초 노트북에서 이미 모델 선택에 사용했으므로 별도 감사 평가로 유지합니다. 감사 평가와 동결 평가 결과로 공개 설정을 다시 조정하지 않습니다.

## 모듈

| 모듈 | 역할 |
| --- | --- |
| `data.py` | 데이터 파일 목록, 트랙 분리 및 고정 평가 입력 |
| `models.py` | 표준 교사 및 소형 학생 모델 |
| `training.py` | 지도학습과 증류 최적화, 체크포인트 및 검증 |
| `experiments.py` | 예산을 제한한 Kaggle 실험 단계와 중단 판단 |
| `evaluation.py` | 동결 모델 평가, 혼동행렬 및 예측 기록 |
| `benchmark.py` | 동일 입력을 사용한 예열 후 CPU 측정 |
| `export.py` | 학습 자료로만 보정한 FP32 및 INT8 TFLite 변환 |
| `runtime.py` | 저장 모델 로딩과 로컬 이미지 추론 |
| `__main__.py` | 명시적인 CLI 진입점 |

실제 파일명과 공개 결과는 저장소에서 확인할 수 있습니다. 구조나 인터페이스가 준비되어 있다는 사실만으로 학습과 배포 검증에 성공했다고 주장하지 않으며, 결과 및 검증 보고서로 수행 근거를 제공합니다.

참고: [MobileNetV2 전처리](https://keras.io/api/applications/mobilenet/), [지식증류 논문](https://arxiv.org/abs/1503.02531), [GTSRB](https://benchmark.ini.rub.de/gtsrb_dataset.html).
